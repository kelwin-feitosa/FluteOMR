# Exemplos e recursos

Reserve esta pasta para exemplos sintéticos produzidos pelo projeto ou materiais
com uso e distribuição verificados. Para cada material de terceiros, registre
origem, autoria, licença e condições de redistribuição antes de adicioná-lo.

Nenhuma partitura está incluída nesta etapa. Guarde partituras pessoais em
`assets/private/` ou `private/`, ambos ignorados pelo Git. Revise sempre os arquivos
antes de adicioná-los: `.gitignore` não garante autorização de distribuição.
